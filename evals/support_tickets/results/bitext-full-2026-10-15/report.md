## Setup

- **Jev**: `jev-latest`, typed choice, temperature n/a, scope full, concurrency up to 8.
- **GPT-4o mini zero-shot**: `gpt-4o-mini`, zero-shot, temperature 0, scope full, concurrency up to 32.
- **GPT-4o mini few-shot**: `gpt-4o-mini`, few-shot, temperature 0, scope full, concurrency up to 24.
- **GPT-4o zero-shot**: `gpt-4o`, zero-shot, temperature 0, scope subset, concurrency up to 10.
- **GPT-4o few-shot**: `gpt-4o`, few-shot, temperature 0, scope subset, concurrency up to 6.
- **GPT-6 Astra zero-shot**: `gpt-6-astra`, zero-shot, temperature default (1); model rejects 0; reasoning_effort=low, scope flagship, concurrency up to 12.
- **GPT-6 Astra few-shot**: `gpt-6-astra`, few-shot, temperature default (1); model rejects 0; reasoning_effort=low, scope flagship, concurrency up to 12.

- Price `jev`: input $0.042/M, cached input n/a, output $0.0/M (TypeSafe list price, verified 2026-09-27 at docs.typesafe.ai/models).

## Files and reproduction

- `raw/<config>/run<k>.jsonl.gz`: one record per call (row index, ticket id, true and predicted label, the raw model reply, token usage including cached and reasoning tokens, latency, attempts, errors). Ticket text is not repeated; it comes from the pinned dataset.
- `summary.csv` (one row per configuration, run and scope), `per_class.csv` (per intent precision, recall, F1 and support), `results.json` (aggregates, latency, agreement, paired tests) and `manifest.json` (dataset hash, seeds, exemplar, subset and flagship row indexes, prices).
- Reproduce: `uv run python evals/support_tickets/full_bench.py --estimate`, then `--smoke`, `--run --flagship-per-intent 30` and `--finalize --flagship-per-intent 30`. Keys are read from the environment (`OPENAI_API_KEY`, `TYPESAFE_API_KEY`).

## Caveats

- Bitext tickets are synthetic with clean labels; real support traffic will usually score lower.
- Latency is the HTTP latency of the attempt that succeeded, measured with several requests in flight from one Mac; it depends on concurrency, the network and the provider's load at the time. It is computed from runner 2 records only (the first 8,447 records were timed by an event loop starved by a runner bug; their predictions and costs are kept) and excludes each run's first minute, while the runner was still reading its checkpoint files. Otherwise the runner's event loop fell behind by up to about 50 to 100 ms at its worst moment in a minute, so treat latency differences of a few milliseconds as noise.
- Cost is reported tokens times list price, with OpenAI's cached input rate where the response reported cached tokens. Jev bills input only.
- GPT-6 Astra is a reasoning model that rejects temperature 0; it ran at its default temperature (1) with reasoning_effort=low, so its run to run variance is not comparable with the temperature 0 baselines.
- Invalid outputs (not one of the 27 labels) count as wrong. Rows that still had an API error after retries are left out, and a run is only reported when it is complete.
