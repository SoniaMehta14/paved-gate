Setup and caveats

  • The 10 paired tests against Jev are not corrected for multiple comparisons, so borderline results should not be read as wins.
  • Three evaluation sets, nested: the full set (every ticket except the 27 few-shot exemplars), a stratified subset (100 per intent) and the flagship set (30 per intent, drawn from the subset). GPT-4o ran on the subset; GPT-6 Astra only on the flagship set.
  • GPT-6 Astra is a reasoning model that rejects temperature 0. It ran at its default temperature (1) with reasoning_effort=low, so its run-to-run variance is not comparable with the temperature 0 baselines.
  • This run did not test real support traffic.
  • Latency is the HTTP latency of the successful attempt, measured with several requests in flight from one Mac. It depends on concurrency, the network and provider load, so treat differences of a few milliseconds as noise
  • Cost is reported tokens × list price, with OpenAI's cached input rate where the response reported cached tokens. Jev bills input only.
  • Invalid outputs (not one of the 27 labels) count as wrong. Rows that still had an API error after retries are left out, and a run is only reported when it is complete.
